Re-vendor with `make vendor-supabase UPSTREAM=<checkout>` and review the diff.
- **Unverified:** Docker Desktop, Trivy on the third-party Supabase images, memory under load, Claude Code loading the `.claude/` hook and commands (the hook was only simulated).
- Feature 02 now combines process-local single-flight with a database lease for multi-instance refresh coordination. If an API instance crashes after GoTrue rotates a refresh token but before Postgres stores it, recovery after lease expiry can still invalidate the session. SMTP supports explicit implicit-TLS or required-STARTTLS relays with paired credentials; Mailpit remains the local no-auth default. A production relay and certificate chain still need environment-level verification.
- RustFS (`rustfs/rustfs:1.0.1`) now runs the S3-compatible `ObjectStore` contract test in CI (feature 08).
- `.trivyignore.yaml` has no active exceptions. The custom pinned Caddy build updates go-jose v4 and x/net; GitHub Trivy scans on PRs #13 and #14 passed with no HIGH/CRITICAL findings. The upstream dependency graph still contains go-jose v3.0.5, for which the advisory has no patched release; see ADR 0017.
- No branch protection: GitHub does not offer it for private repositories without Pro, so CI cannot be made mandatory. Mention in the README.
- oxfmt is beta (its CSS formatter lowercased font names); the revisit triggers are in ADR 0005.
- Local container checks ran on Podman (no BuildKit, arm64 only); CI is real Docker on amd64. Docker Desktop on a reviewer's machine is untested.
- The AI review has not run live yet (needs the secrets above); review quality from a free model is unproven.
